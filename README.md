# Interface Element (IEL) [![License](https://img.shields.io/badge/License-Apache%202.0-blue.svg)](https://opensource.org/licenses/Apache-2.0) [![NuGet Version](https://img.shields.io/nuget/v/IEL.svg?style=flat&label=NuGet)](https://www.nuget.org/packages/IEL/)
[![Подписаться на канал](https://img.shields.io/badge/Telegram-Oper_Page_les-2CA5E0?style=for-the-badge&logo=telegram)](https://t.me/OperPageLes)<br>
Библиотека предоставляет переопределённые пользовательские объекты интерфейса со своей логикой и функциями<br>
Является низкоуровневой библиотекой, предоставляя лишь данные и примитивное управление над реализованными функциями

## Какие объекты предоставляет библиотека
В библиотеке присутствуют элементы интерфейса, такие как:
+ `IELButtonText`/`IELButtonImage`: Данные объекты представляют собой элементы интерфейса - кнопки<br>
Реализованы от базового класса `IELButtonBase`, который предоставляет наследование для видов кнопок с настраиваемым содержимым _(Текстом, изображением и т.д)_<br>
+ `IELBlockInfo`: Объект, отображающий содерживое. Является наследуемым от `IELContainerBase`<br>
Базовый класс предоставляет использование с помощью реализованной функции персонализации и анимирования, отображает контент в контейнере
+ `IELTextBox`: Объект реализует стандартный `TextBox`, меняя визуальную чась, создавая единый интерфейс<br>
+ `IELBlockMessage`: Объект, который показывает сообщение. Может быть примагничен к объекту показывающее сообщение, находясь в глобальном контейнере
+ `IELContentController`: Объект, отображающий содержимое внутри себя, предоставляя переключение между контейнерами. Содержимое может являться объектом `Page`, либо любым другим элементом интерфейса
+ `IELPanelAction`: Объект, похожий на `IELContentController`, за исключением что предоставляется возможность управления кнопками с помощью клавиш, без участия выши внутри содержимого контейнера<br>
_Для этого элемента рекомендуется использовать контейнер типа `Page`_
+ `IELButtonTextKey`/`IELButtonImageKey`: Те же кнопки, но с возможностью привязки к конкретной клавише клавиатуры<br>
_Рекомендуется использовать для `IELPanelAction`_

## Как работает персонализация объектов
Персонализация в IEL представлена несколькими структурами и может наследоваться другими библиотеками для реализации хранения или использования<br>
+ Структура `Color32` хранит массив байт для корректной обработки данных внутри использования цветов, может быть переконвертирована в структуру `Color` от _System.Windows.Media_
+ Структура `QData` представляет обёртку над данными от `Color32`. Хранит в себе 4 цвета, отвечающие за своё состояние отображения объекта UI
+ Структура `PaletteData` является также обёрткой на уровень выше, где данные представляются 3-мя спектрами отдельных `QData`: Фон объекта, границы и текст

Также сам объект UI, наследованный от базового класса `IELObjectBase` имеет доступ к полям класса `PaletteSpectrum`, в котором можно выделять отдельный спектр, направлять отображение, изменять данные<br>
Также через `PaletteSpectrum` можно получить объект `SolidColorBrush` для подключения его к стороннему объекту в пользовательском элементе интерфейса<br>
Изменение данных происходит внутри `PaletteSpectrum`, этот класс нельзя и не нужно создавать отдельно<br>
Он является управляемой единицей для элемента интерфейса, изменять данные для него можно с помощью `PaletteData` для всего объекта и `QData` для одного из спектров<br>
Доступ к смектрам осуществляется с помощью переопределённых свойств _Background, BorderBrush, Foreground_<br>
Через свойство `Palette` можно изменять данные отображения польностью<br>
